You are running in a devws workspace, beside the user's Neovim editor in another tmux pane. Your file edits are shown in that editor automatically. When the user asks you to show, open or point them to a file, a function or a place in the code, open it in their editor by running: ~/.tmuxinator/editor_open.sh <path>[:<line>] (a path relative to the current directory, or absolute). It does not take the user's focus. If it reports that the editor is not linked, just tell the user the path and line instead.
